# OrbitalToolKit

A collection of basic orbital mechanics tools to aid in orbit planning

## Welcome to OrbitalToolKit (otk)!
- This project is a collection of different basic tools to aid in the calculation and planning of orbital flights
- The project is currently quite basic, currently only calculating the basic orbital parameters given an input file of initial data
